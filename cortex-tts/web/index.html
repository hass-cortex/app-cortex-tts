Models

Weights download on demand. Only one model stays in memory at a time by default; the larger ones need 1–2 GB each.

Settings

Stored by the app; a change takes effect on the next request. reload settings are bound when a model loads, so changing one drops what is resident. restart also sizes the maths libraries' thread pools at start-up.

Defaults

Used when a request names none.

A request that names no language is read in this voice's; OmniVoice and Qwen3-TTS can also be told one outright.

Preload

Off, the first request after a start pays the load; on, the model's memory is held from start-up.

A request may send its own. High values sometimes append an invented syllable; 0 is reproducible on Hojo but makes Qwen3-TTS fail to stop. MOSS and OmniVoice ignore it.

Text switches, per model and language

What a request gets for a switch it leaves out. Left alone, each is the pipeline's call: bare numbers by the model, the Chinese rewrites by the language. The most specific rule wins; a language covers every tag it prefixes (zh covers zh-TW).

Roughly 0.8 GB for the 40M, 1.1 GB OmniVoice, 1.5 GB Qwen3-TTS, 2 GB each for the 80M and MOSS. At 1 they swap on demand.

Playback that catches the renderer at a sentence end is heard as a longer pause between sentences, which is where a pause belongs — so the opening need not be held against it, and the first word comes sooner. A cut inside a sentence never earns this, and neither does a model that streams audio while it renders. 0 holds until nothing can ever run dry.

Drop a model this long after its last request; 0 keeps it until something evicts it. Worth setting on a GPU shared with another workload.

Cloned voices

cloning models

One recording becomes a voice on every model that clones, under the same id.

  • Six to ten seconds of clean speech that starts talking straight away. Shorter than 2 s or longer than 20 s is refused, and past ten buys nothing on any model here.
  • End on a finished sentence. A clip cut by a clock is refused: it teaches the model that sentences end mid-word.
  • Clean beats long. The 80M reads only the first six seconds; MOSS, OmniVoice and Qwen3-TTS read all of it.
  • Type exactly what is said. The transcript is what tells a model which sounds map to which text, and a wrong one degrades the clone with no error. It is stored as you type it — nothing here rewrites it.
  • Chinese goes in Simplified. Every model reads Traditional glyphs as the wrong sounds rather than failing on them (measured: 32% character error against 4% converted), so convert the transcript yourself. Every model also reads mainland-standard, so where Taiwan says it differently, write a homophone that forces the reading: 夕阳 comes out xī yáng, and 系阳 — not a word, but read xì yáng — is how you get the Taiwanese one.
  • Label the language whole. A voice tagged zh-TW is Taiwanese, so text read in it gets Taiwan readings by default; zh promises only Chinese.

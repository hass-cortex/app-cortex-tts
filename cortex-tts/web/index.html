Models

Weights download on demand. Only one model stays in memory at a time by default — the larger two need about 2 GB each.

Settings

Saved here, not in the app's configuration — a change takes effect on the next request. The three marked reload are fixed when a model is loaded, so adopting one drops what is resident and the next reply loads it again.

Used when a request names none.

Picking the voice is picking the language; no model takes a language parameter.

0 lets the runtime decide. More is not faster: measured on four cores, 1.17x real time at one thread, 1.05x at two, 1.80x at four.

MOSS measured 1.025 on a laptop CPU against 0.354 on a GTX 1650. What the sessions actually got is shown on each loaded card.

The 40M needs about 780 MB, the 80M and MOSS about 2 GB each. At 1 they swap on demand.

The model stops only when it samples its end-of-speech token, so a high value sometimes appends an invented syllable. 0 is reproducible and never over-runs, at the cost of flatter delivery.

Cloned voices

cloning models

A reference recording is a voice on every model that can clone, under the same id. Upload about 6 seconds of clean speech that starts talking straight away — that is exactly how much the speaker encoder reads — plus exactly what is said in it, because the transcript is what tells the model which sounds map to which text.

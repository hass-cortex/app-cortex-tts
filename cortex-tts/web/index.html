Models

Weights download on demand. Only one model stays in memory at a time by default — the larger two need about 2 GB each.

Settings

Saved here, not in the app's configuration — a change takes effect on the next request. Those marked reload are fixed when a model is loaded, so adopting one drops what is resident and the next reply loads it again. The one marked restart also sizes the maths libraries' thread pools when the app starts, so its full effect needs an app restart.

Defaults

Used when a request names none.

Picking the voice is picking the language; no model takes a language parameter.

Preload

Off, the first request after a start pays the load — several seconds on the larger models. On, the app holds that model's memory from the moment it comes up, whether or not anything asks it to speak.

A request may send its own. The model stops only when it samples its end-of-speech token, so a high value sometimes appends an invented syllable. 0 is reproducible and never over-runs on the Hojo models — but not on Qwen3-TTS, where greedy decoding often fails to stop at all and the reply is cut off at its ceiling instead. MOSS and OmniVoice ignore this setting and say so.

How this host runs them

0 lets the runtime decide. Resident models adopt it on their next load; BLAS and OpenMP only on an app restart. More is not always faster, and the models disagree with each other — some are slower at four threads than at two. Change it, then read the card's measured figure for the model you use.

MOSS measured 1.025 on a laptop CPU against 0.354 on a GTX 1650. What the sessions actually got is shown on each loaded card.

The 40M needs about 780 MB, OmniVoice about 1.1 GB, Qwen3-TTS about 1.5 GB, the 80M and MOSS about 2 GB each. At 1 they swap on demand; lowering it evicts the least recently used at once.

Cloned voices

cloning models

One recording becomes a voice on every model that clones, under the same id.

  • 6–20 seconds of clean speech that starts talking straight away.
  • End on a finished sentence. A clip cut by a clock is refused: it teaches the model that sentences end mid-word.
  • Clean beats long. The 80M reads only the first six seconds; MOSS, OmniVoice and Qwen3-TTS read all of it.
  • Type exactly what is said. The transcript is what tells the model which sounds map to which text.
